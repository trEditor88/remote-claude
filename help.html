원격 Claude 사용 설명서

휴대폰에서 집 PC 의 Claude Code 에게 일을 시키고, 진행 상황과 결과를 실시간으로 받아 보는 개인 전용 사이트입니다.

이 사이트는 PC 주인 한 사람만 씁니다. 다른 사람은 로그인할 수 없습니다.

1. 로그인과 보안 코드

  1. 원격 Claude를 열고 아이디·비밀번호를 넣은 뒤 들어가기를 누릅니다.
  2. 처음 로그인하면 보안 코드 정하기 창이 뜹니다. 6자리 숫자를 정하세요. 같은 숫자 반복(111111)이나 연속 숫자(123456)는 안 됩니다.
  3. 다음부터 새 기기나 새 장소(다른 와이파이·통신망)에서 로그인하면 이 6자리 코드를 한 번 더 묻습니다.
  • 로그인 유지는 기본으로 켜져 있습니다. 끄면 브라우저를 닫거나 12시간이 지나면 다시 로그인해야 합니다. 남의 기기에서는 꺼 두세요.
  • 너무 많이 틀리면 15~30분 동안 잠깁니다. 잠깐 기다렸다 다시 하세요.

2. 화면 알아보기

위치보이는 것뜻
맨 위PC 연결됨 / PC 꺼짐 · N분 전집 PC 가 일을 받을 수 있는지 알려 줍니다. 꺼져 있어도 요청은 쌓였다가 PC 가 켜지면 실행됩니다.
맨 위 오른쪽톱니(설정), 나가기보안 설정과 로그아웃.
왼쪽(휴대폰은 ☰)새 대화, 대화 목록고정한 대화 → 폴더 → 최근 대화 순서. 점은 실행 중·대기 중 표시입니다.
가운데대화 내용새 대화에서는 "무엇을 시킬까요?"와 추천 카드 4개가 보입니다.

3. 일 시키기

  1. 아래 입력창에 할 일을 적습니다(최대 4000자). 추천 카드를 눌러도 됩니다.
  2. 필요하면 사진을 붙입니다. 사진 버튼, 붙여넣기, 끌어놓기 모두 되고 한 번에 4장까지입니다.
  3. 권한을 고릅니다.
    • 수정 허용 — 파일을 고치고 명령도 실행합니다.
    • 읽기만 — 파일을 고치지 않고 살펴본 뒤 계획만 세웁니다. 처음 보는 일이면 이걸로 먼저 시켜 보세요.
  4. 모델을 고릅니다.
    모델언제
    기본 · Opus보통은 이걸로.
    Fable · 최고 성능아주 어려운 일. 사용량을 Opus 의 2.5배쯤 씁니다.
    Sonnet · 빠르게간단하고 빨리 끝낼 일.
    Haiku · 가장 빠르게아주 짧은 질문. 복잡한 일은 실수할 수 있습니다.
  5. 보내기(또는 Enter)를 누릅니다. PC 에서는 Shift+Enter 로 줄을 바꿉니다.

빠른 작업

자주 하는 일(상태 점검, 서버 테스트, 기록 확인, 사이트 배포)을 버튼 한 번으로 보냅니다. 배포는 실행 전에 한 번 더 묻습니다.

위험 허용

안전을 위해 배포·푸시·데이터 삭제·폴더 통째 삭제·시스템 설정·비밀 값 읽기 같은 위험한 명령은 기본으로 막혀 있습니다. 꼭 필요할 때만 위험 허용을 켜고 허용을 누르세요. 그 요청 하나에만 적용되고, 보내고 나면 저절로 꺼집니다.

4. 진행 보기·멈추기

상태뜻할 수 있는 것
대기PC 가 아직 받지 않음취소
실행 중작업 중. 경과 시간과 실시간 작업 기록(최근 8줄)이 보입니다.중지 → 멈추기
완료끝남. 결과가 바로 아래에 보입니다.전체 보기 복사, 접힌 작업 기록
오류 / 중지됨실패했거나 멈춤다시 쓰기
  • 같은 대화에서 다시 보내면 Claude 가 앞 내용을 기억하고 이어서 합니다. 주제가 바뀌면 새 대화를 쓰세요.
  • 위험한 명령이 막히면 "위험한 명령을 막았어요" 상자가 뜹니다. 정말 필요하면 허용하고 다시 보내기를 누르세요.
  • 끝나면 "요청이 끝났어요" 알림이 뜨고 탭 제목 앞에 (완료)가 붙습니다. 다른 앱을 보고 있어도 됩니다.

5. 대화 정리하기

대화 옆 ⋯ 메뉴:

  • 이름 바꾸기 — 비워 두면 첫 요청이 제목이 됩니다.
  • 맨 위에 고정 / 고정 해제
  • 폴더로 이동 — 새 폴더 이름을 적고 만들어서 옮기기. 폴더에서 빼기로 다시 꺼냅니다.
  • 내보내기 (.md) — 대화를 문서 파일로 저장합니다.
  • 삭제 — 되돌릴 수 없습니다.

폴더 옆 ⋯ 메뉴에는 이 폴더에 새 대화, 폴더 이름 바꾸기, 폴더 풀기가 있습니다. 목록에는 고정·폴더 대화와 최근 대화를 합쳐 100개까지 보입니다.

6. 보안 설정 (톱니)

항목하는 일
보안 코드6자리 코드를 정하거나 바꿉니다. 바꿀 때는 비밀번호와 지금 코드가 필요합니다.
로그인 유지이 기기에서 로그인을 오래 유지할지 정합니다.
믿는 기기보안 코드로 확인한 기기 수와 지금 로그인된 곳 수. 모두 해제를 누르면 이 기기를 뺀 모든 기기가 로그아웃되고, 다음에 다시 코드를 물어봅니다.
보안 기록 (최근 40개)로그인, 로그인 실패, 잠김, 새 기기 시도, 코드 틀림, 위험 명령 막음 등을 시각·IP·기기와 함께 보여 줍니다.
모르는 기록이 보이면 바로 모두 해제를 누르고, 비밀번호와 보안 코드를 바꾸세요. 화면 위에 "보안 알림 N건" 띠가 뜨면 확인을 눌러 살펴보세요.

7. 홈 화면에 추가

앱처럼 아이콘으로 열 수 있습니다.

  • 아이폰(사파리) — 아래 공유 버튼 → 홈 화면에 추가
  • 안드로이드(크롬) — 오른쪽 위 ⋮ → 홈 화면에 추가(또는 앱 설치)

8. 이럴 땐 이렇게

상황해결
계속 "대기"에서 안 넘어가요맨 위가 PC 꺼짐이면 PC 를 켜세요. 켜지면 쌓인 요청부터 실행합니다. "1분 넘게 기다리는 요청" 띠가 계속 뜨면 PC 의 원격 Claude 다리가 꺼진 것입니다(5분 안에 저절로 다시 켜짐).
오류로 끝났어요작업 기록을 펼쳐 마지막 줄을 봅니다. 다시 쓰기로 고쳐 보내세요.
너무 오래 걸려요중지 → 멈추기. 일을 작게 나눠 다시 시키세요.
"보안 코드가 맞지 않아요"남은 기회 안에 다시 넣으세요. 시간이 지나면 처음부터 다시 로그인.
"관리자 계정만 쓸 수 있습니다"이 사이트는 PC 주인 계정으로만 들어갈 수 있습니다.
휴대폰을 잃어버렸어요다른 기기로 로그인 → 설정 → 믿는 기기 모두 해제 → 비밀번호와 보안 코드 변경.
