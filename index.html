원격 Claude

휴대폰에서 요청하면 서버의 Claude Code가 실행하고 결과를 돌려줍니다.

보안 코드 확인

처음 쓰는 기기나 새로운 장소(IP)에서 로그인했어요. 미리 정해 둔 6자리 보안 코드를 넣어 주세요.

공유 계정(HEO Works)으로 들어갑니다. HEO Works 에서 로그인하면 바로 열려요. 관리자가 원격 Claude 사용을 허락한 계정만 쓸 수 있어요.

고정·폴더 대화와 최근 대화를 합쳐 100개까지 보여요.

새 대화

1분 넘게 기다리는 요청이 있어요. PC가 꺼져 있거나 tools\remote_claude.py 가 멈췄을 수 있어요.

무엇을 시킬까요?

연결한 PC에서 Claude Code가 일합니다. 아래에서 골라 고쳐 쓰거나 직접 적어 보내세요.

알아 두면 좋아요

  • 대화마다 따로 기억해요. 다른 일을 시킬 때는 새 대화로 시작하세요.
  • 읽기만을 고르면 파일을 고치지 않고 살펴본 뒤 계획만 세워요.
  • 실행 중에는 Claude가 읽는 파일과 실행하는 명령이 실시간으로 보이고, 언제든 중지할 수 있어요.
  • 왼쪽 대화의 ⋯을 누르면 이름 바꾸기·고정·폴더 정리·내보내기·삭제를 할 수 있어요.
  • PC가 꺼져 있어도 보내 둘 수 있어요. PC가 켜지면 순서대로 실행돼요.
